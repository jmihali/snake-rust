# Rust Snake

This is a Rust implementation of the popular 2D game Snake.

I create this project as a hobby project in order to practice my Rust programmig skills. I am still a beginner in Rust, so there are for sure things not done the most perfect way. I tried to follow good programming practices and clean architecture principles. Anyone is welcome to give feedback, create PRs or write an issue.

To start the game, simply execute:

``cargo run -- --grid-width 20 --grid-height 20 --speed``

An autonomous game mode has been implemented. To run it, add the `--ai` flag to the cargo command.
